# Leakage gate — first run, 2026-11-10

Run against the frozen atlas class alone (82 items after removing 8 exact
duplicates). **No scoring has occurred.** This is a property of the corpus.

Command: `python3 atlas2/tools/leakage_check.py`

## Result: the corpus leaks. Gate FAILS.

| Target | content AUC | style AUC | length-only AUC | perm p |
|---|---|---|---|---|
| authoring session (n=46, binary) | 1.000 | 1.000 | **1.000** | 0.005 |
| physics category (n=48, 5-way) | 0.930 | 0.859 | **0.784** | 0.005 |

Field lengths by authoring session:

```
salvo-cs-001                     mean 52.0 words  sd 4.4  n=26
h2_discovery_session_2026-04-16  mean 48.0 words  sd 6.2  n=20
```

## What this means

**Lengths alone separate the two dominant authoring sessions perfectly.** The
distributions are tight (sd 4.4 and 6.2) and their means differ by four words, so
a classifier given nothing but "how many words are in each of the six fields"
reaches AUC 1.000 with p = 0.005 under permutation.

That is not a subtle bias. It is a complete fingerprint. Anyone — a reviewer, a
model, or a trivial script — can tell who wrote an item without reading it.

**The style-only result is partly the same signal.** The style feature set includes
length buckets, so style ≈ content ≈ length all at or near 1.000 is one effect
seen three ways, not three independent leaks. The length-only column exists to say
that plainly rather than let the style number look like an independent finding.

**Physics category is also length-predictable at 0.784.** That is a confound for
every target in this corpus, not only author: field length carries category
information, so any comparison across categories is contaminated until lengths are
equalised.

## Consequence for the benchmark

Equalising field lengths across classes is not a nicety, it is a precondition. Until
it happens:

- gold written by an outside author will be separable from decoys by brevity;
- the "fields only" condition would be measuring prose length, not correspondence
  quality;
- any AUROC obtained would be uninterpretable.

## Gate rules now in `PREREGISTRATION.md`

1. Equalise field-length distributions across classes before scoring.
2. Re-run this check; **style-only and length-only AUC on the class label must fall
   below 0.65**.
3. Commit the gate report with the items. A run without it is void.

## What is still unknown

This run had **no gold and no decoys**, so it could not measure the thing the gate
actually cares about — whether *class* is predictable from style. It measured the
best available proxy: whether a hidden attribute known to differ by authorship is
predictable from style. It is.

When gold and decoys exist, the same script should be pointed at the `class` label
directly. That is the real gate; this is the rehearsal.
